# PDF-page-editor
A python based tool that allows the user to add or remove pages to an other pdf file 
PRIMARY PURPOSE:
This is basically built for students in courses such as GCE Alevels,GCE Olevels,Ed excel and many other boards that have their past papers available online. This basically allows the student or the user to open multiple pdfs at once and then using clicks of mouse add one pdf page to another new pdf that you create like while building topical past papers of any board like alevel,etc. You quickly skim through the question to see if its of which topic and then you add it there to that topic's pdf file.

HOW TO USE:
Copy paste the code from the file called Main-code after installing all the required libraries i.e (PyQt6 and PyMuPDF) libraries once you have installed them in the terminal in which you will run the code paste the code into your any python editor and click on Run.

A popup window will appear showing buttons like "open pdfs,create new pdf" etc. Select the option of create new pdf selecting its location and name, repeat the process for another pdf naming it for e.g Markscheme of the question paper that you are about to make once you have made these 2 pdfs now open all your required pdfs (i would prefer opening less files at instant like 8-10 files in one go) to prevent the processor from lagging.

After all the files have finally loaded now click on any page of the pdf while holding "ctrl" to add that page onto the first pdf you created and if you click on any page while holding "ctrl+shift" it will be added to your second pdf you created i.e the  markscheme to remove any page you accidently added in a pdf "click on the page while holding "ctrl+alt" to remove that page from the pdf.
